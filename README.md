## 如何使用

1. 進入網站，在左側導覽選擇 **文章與案例**；手機版可從首頁文章入口進入。
2. 從「保險實務」或「保險法規」挑選一章，先讀導讀、生活例子、名詞解釋及易錯觀念。
3. 展開該章的原題案例，對照題庫原始答案與解析；按「到測驗模式作答」或「開始本章測驗」。
4. 答錯的題目會留在原網站的錯題複習紀錄；讀完可標記本章觀念已閱讀。
